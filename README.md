# MacrophageFramework manuscript – Analysis scripts

This repository contains the R and Python scripts used to perform the analyses and generate the figures reported in the manuscript describing MacrophageFramework.

## Repository organization

- `Human_atlas/`: analysis of the human macrophage atlas and clinical-group comparisons.
- `TMS_atlas/`: analysis of the TMS macrophage atlas.
- `Figure2_mouse_lung__human_ovarian/`: analyses of the mouse lung and human ovarian datasets.
- `Sensitivity/`: ontology robustness and sequencing-depth sensitivity analyses.
- `Benchmark/`: benchmarking analyses against CellTypist and MacAnalyzeR.

## Software requirements

The analyses were performed using R and Python. Required packages and dependencies are specified within the individual scripts.

The unweighted version of the MacrophageFramework R package used in this manuscript is available in the [`manuscript-unweighted-v1.0.0` release](https://github.com/AlessandroPalma-hub/MacrophageFramework/releases/tag/manuscript-unweighted-v1.0.0).

## Data availability

The scripts operate on publicly available datasets. Accession numbers and data-loading instructions are provided within the corresponding scripts.

## Reproducibility

Scripts are provided to document and support the analyses reported in the manuscript. Please refer to individual scripts for dataset-specific processing and analysis steps.
